# ⚡ Ultra-Pro Telegram Bot Host Engine

This is a Master Telegram Bot that can host and run other Python scripts and Telegram Bots 24/7 on cloud servers like Render.

## 🚀 Features
- 24/7 Uptime with Flask HTTP Server
- Auto dependency detection and `pip install`
- Support for uploading `.py` and `requirements.txt`
- Live control panel (Status, Stop, Restart)
